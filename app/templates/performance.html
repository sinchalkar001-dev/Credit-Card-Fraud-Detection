How these scores were measured

{{ split.test_rows | number }} of the {{ model_info.dataset.rows | number }} applications were set aside before training, keeping the same mix of good and bad, and are scored here once. The model never saw them.

Bad applications are outnumbered seven to three, so in training each one counts as much as 2.33 good ones. That makes the model catch more of them, at the price of more false alarms.

The same settings fitted without weights, for comparison. It is right more often overall because it leans towards the larger class, and it lets more bad applications through. It is not the model in use.
